User Management and API FETCHING

Using the API: https://api.slingacademy.com/v1/sample-data/users

Build a React application with:

Register & Login – Create forms with validation and store login status in localStorage.
Dashboard – Fetch and display all users from the API. Implement search.
User Details – On clicking View Details, navigate to a separate page and fetch the particular user using their ID.
Logout – Clear localStorage and redirect to Login.

Must use: React Router, useState, useEffect, useParams, fetch(), localStorage, API integration, loading & error handling.
